# osu!step

This is a osu! ruleset designed to forwardport (if that term exists!) features of Stepmania into osu!, notably its lenient, non-combo sensitive holds, rolls, and bombs.

Currently, holds are implemented and functional, including NG! (for dropped) and OK! (for held) holds. The timing for re-holding is fixed at 250ms.

Planned features are rolls (key spam) and bombs (do not press them), as well as their integration into the osu! format to be able to share beatmaps using this ruleset.

Thank you for checking it out!
